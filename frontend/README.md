# Frontend (Cliente web reactivo)

## Detalles Cliente Web reactivo
- vue 3 
- vue-router 
- vue-i18n
- vite 4
- tailwindcss 3
- vuetify 3
- pinia
- socket.io-client 
- mdi/font

---

> Se requiere Node v16.14.2 & npm 8.5.0

- Ejecutar `npm i`
- Correr el proyecto, ejecutar `npm run dev`, 
- Al terminar de desarrollar y una vez guardado el proyecto, ejecutar `npm run build`, para que se actualice la build que contiene el proyecto lb3 en `lb3_p2p_match/backend/client`
